### 冰箱动作与连续状态

2026-10-19 实验使用隔离 BrainApplication、原 Runtime／Runner／Verifier、真实导航代码和原生 O6 物理模型。计划为用户指定的导航、开门、关门三步，没有让 LLM 在线生成动作。独立站位探测与导航后的完整任务分开统计。[P6](#e-p6)

| 探测／完整任务 | 结果及不能忽略的失败 |
| --- | --- |
| probe01 | 曾开到 30.9173°、曾接近闭门，但撤手再次带开，终态 13.8389°，失败 |
| probe02 | 解钩张手后下撤收手，最终 0.02050°，独立操控通过；不代表完整任务通过 |
| 完整任务 01 | 导航成功；右肩 yaw 连杆与躯干自碰撞，穿透 0.13403mm，门未打开 |
| 完整任务 02 | 导航成功；指尖触柜，接触力 80.2448N 触发停止，门未打开 |
| 完整任务 03 | 导航成功；固定 4 秒等待不满足站稳门限，抬手前拒绝；后改为同门限的动态等待，不能倒填该轮成功 |
| 完整任务 04 | 导航成功，门曾开到 34.5965°；左肩自碰撞 0.10635mm，未完成开门核验或关门 |

任务前缀 `brain-ros-o6-fridge-open-close-20261019-`，各回合独立留账。导航到操控交接保存 MuJoCo 完整积分状态和 SONIC 历史，不重设机器人或门状态，任一时刻只有一个进程推进物理回合。仿真时钟暂停不是实体停止保证。

原记录使用的机器人非地面穿透 0.1mm、冰箱内部穿透 0.001mm、单手接触力合量 60N 等停止门限保留。开门须达到角度、速度、稳定保持和接触要求；关门还须满足离开冰箱、撤手和停止要求。该资产门阻尼／摩擦未做实物标定，不能推断真机能力。

### 成功证据的层次

协议模拟回执、动作数组有限、真实策略调用、物理轨迹满足门限和真机完成是不同事实。端口可达、进程正常退出、中途曾闭门或手指闭合均不足以认定抓放／开关门成功。

SIMPLE 的接待物理回合与通用单步接口各有边界；原执行控制器、任务／命令身份、失败重试与停止证据保持可追溯。以模拟操控完成的导航流程见[导航与定位](多端联调_导航与定位.md)，不计入真实操控通过。

### 旧 O7 失败与服务验证

已经由本机现有 Planner 为“抓起桌上的可乐并稳定持有”生成单步 `抓取 coke`，经 Runtime 提交到远端。
首个真实命令为 `simple-o7-1-bd114bc9d8b0`，远端 episode 为 `cbe03d2cbc45d503fef94252`。

该 O7 场景的可达性问题尚未修复。本次随后识别并接入了既有的 O6 原生任务，结果见下一节；没有修改其控制算法或场景资产。

操控使用远端已有接触规划器、SONIC 原始 ONNX decoder 和原生 O6 手部 PD；在独立副本中增加关门、解钩与撤手阶段。它不是 GR00T 推理或已训练的开关门策略。计划为用户指定的固定导航、开门、关门步骤，本轮没有让 LLM 在线生成动作。

- FQ 资产锁定 `711400c5fbd1f7946ef8bd72477ae457916fce87`；原生模型 `nq=61`、`nv=60`、41 个执行器。与此前 65 个 qpos 的 ROS 导航模型区分。
- 复用隔离导航副本原有五点准入和路径补点修正；本轮只使用冰箱首点。导航控制源码和到达门限没有为成功降级。
- 使用该资产中的可动冰箱；地图与合成扫描中的冰箱位置同步到该版本。定位为仿真真值，不代表实际传感器验收。
- 身体自由浮动，不使用身体固定、手门焊接或门铰链驱动器。该资产右门摩擦损失、阻尼为零，仍未做实物阻力标定。
- 接近、接触与关门保留既有机器人非地面穿透 0.1 mm、冰箱内部穿透 0.001 mm 和单手接触力合量 60 N 的停止门限。

<a id="e-p6-s2"></a>

### 连续状态与任务权威

大脑是唯一任务状态权威，实验执行桥只保存带原 task_id／command_id 的下游命令与结果，不调度下一步。导航完成后仍核对原命令成功、到位、停止及无活动命令。

导航模拟器停止推进物理世界，保存 MuJoCo `mjSTATE_INTEGRATION` 完整积分状态及 SONIC 历史。操控进程读取同一模型与状态；边界逐项比较 qpos／qvel，不重设机器人站位、关节、门角或速度。任一时刻只有一个进程推进该物理回合。开门到位后暂停仿真时钟，待大脑核验并派发原任务的关门命令后继续。仿真时钟暂停不等于实体机器人停止保证。

开门成功要求测得门角至少 25°、门速不高于 1°/s、稳定保持并有手门接触。关门成功要求最终门角绝对值不高于 2°、门速不高于 1°/s、双手离开冰箱、撤手结束；最终底座速度还须低于 0.08 m/s。进程正常退出、中途曾经闭门或手指闭合都不足以通过。

本轮入口、适配器和控制器保存在实验目录；没有将该实验接口部署为正式接待能力。原 ROS 导航桥接的仅导航声明及正式 VLA pick/place 合同保持其原含义，参见[ROS 仿真实验接口](../simulation/backends/ros_navigation/README.md)及[操控接口](接口说明_操控VLA.md)。
