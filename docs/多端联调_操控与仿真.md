## 问题与闭环

### 冰箱动作与连续状态

2026-10-19 实验使用隔离 BrainApplication、原 Runtime／Runner／Verifier、真实导航代码和原生 O6 物理模型。计划为用户指定的导航、开门、关门三步，没有让 LLM 在线生成动作。独立站位探测与导航后的完整任务分开统计。[P6](#e-p6)

| 探测／完整任务 | 结果及不能忽略的失败 |
| --- | --- |
| probe01 | 曾开到 30.9173°、曾接近闭门，但撤手再次带开，终态 13.8389°，失败 |
| probe02 | 解钩张手后下撤收手，最终 0.02050°，独立操控通过；不代表完整任务通过 |
| 完整任务 01 | 导航成功；右肩 yaw 连杆与躯干自碰撞，穿透 0.13403mm，门未打开 |
| 完整任务 02 | 导航成功；指尖触柜，接触力 80.2448N 触发停止，门未打开 |
| 完整任务 03 | 导航成功；固定 4 秒等待不满足站稳门限，抬手前拒绝；后改为同门限的动态等待，不能倒填该轮成功 |
| 完整任务 04 | 导航成功，门曾开到 34.5965°；左肩自碰撞 0.10635mm，未完成开门核验或关门 |

任务前缀 `brain-ros-o6-fridge-open-close-20261019-`，各回合独立留账。导航到操控交接保存 MuJoCo 完整积分状态和 SONIC 历史，不重设机器人或门状态，任一时刻只有一个进程推进物理回合。仿真时钟暂停不是实体停止保证。

原记录使用的机器人非地面穿透 0.1mm、冰箱内部穿透 0.001mm、单手接触力合量 60N 等停止门限保留。开门须达到角度、速度、稳定保持和接触要求；关门还须满足离开冰箱、撤手和停止要求。该资产门阻尼／摩擦未做实物标定，不能推断真机能力。

### 成功证据的层次

协议模拟回执、动作数组有限、真实策略调用、物理轨迹满足门限和真机完成是不同事实。端口可达、进程正常退出、中途曾闭门或手指闭合均不足以认定抓放／开关门成功。

SIMPLE 的接待物理回合与通用单步接口各有边界；原执行控制器、任务／命令身份、失败重试与停止证据保持可追溯。以模拟操控完成的导航流程见[导航与定位](多端联调_导航与定位.md)，不计入真实操控通过。

## 待验证事项

- 冰箱完整任务没有最终通过证据；优先在原停止门限下复验站稳、解钩、撤手与自碰撞，不能因局部开门而关闭问题。
- 真实 GR00T 的放置能力、动作后图像、现场门禁及控制器接管仍按当前 VLA 接口逐项核实。
- 覆盖不同物体、场景、连续回合和外部扰动；固定站位探测与真实导航到位后的动作分别计数。
- 实体动作需独立现场授权；本次文档归并没有启动任何机器人或仿真任务。
