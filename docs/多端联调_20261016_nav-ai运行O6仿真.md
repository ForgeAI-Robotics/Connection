## 链路与结果

大脑实际运行在 nav-ai，加载迁移后的项目配置，通过标准 BrainApplication／Runtime 发布
“开始接待（导航仿真＋操控模拟）”。原导航项目 8001 → 9882 → ROS → SONIC → O6 MuJoCo
运行在原仿真服务器的新隔离容器中；Docker 网络 none、ROS 域 126、SSH UNIX socket。
复用已验证的场景、五点合同及历史导航修正，本轮没有修改控制器、到达门限或任务核验标准。
接口与能力边界见 [ROS 仿真接入](../simulation/backends/ros_navigation/README.md)。

任务 `brain-ros-o6-mixed-20261016-nav-ai-01` 最终为 `succeeded`、11/11，
两次失败、两次经大脑继续接口发起的重试、零跳过。五段导航最终均返回到达且停止，
原始回执与大脑各步骤 PASS 的任务、命令身份一致。抓放回执均明确为
`simulated=true`、`physical_execution=false`，不表示物理抓取或放置。

## 失败、重试与物理接触

relay2 首次位置到达，但导航记录最终朝向偏差 29.33°，超过原 15° 门限；9882 为
`position_reached_yaw_incomplete`／`HOLD_EMERGENCY_STOP`，8001 仍为 `navigating`。
原命令最终在 240 秒期限后返回 `NAVIGATION_EXECUTION_FAILED`、
`Agent navigation result wait timed out`。确认失败、停止、无在途目标及定位就绪后，
通过正常继续接口创建 `-r1` 命令，该段成功。前面的导航和模拟抓取没有重做。

relay3 首次长时间处于 `LATERAL_YAW_SETTLE`，最终原导航返回
`goal timeout after 180.0s; current distance=1.9795830361681614m`。
同样核对原命令失败且停止后重试，`-r1` 成功，后续末段导航及模拟放置完成。
失败回执、定位批准和重试响应均保留，没有跳过、清账本或修改失败为成功。

物理记录为 314260 步、628.52 秒仿真时间，500 Hz 间隔和全部数值有限性检查通过，
最大躯干倾角约 0.14139 rad。**本轮有非地面接触，不能称为无碰撞通过。**
仿真时间 23.848–25.682 秒内，右手食指、中指和手基座与 `office_north` 接触，
共 1071 条接触采样，最大穿透约 0.958 mm；这些是采样数，不是独立碰撞次数。
完整流程通过与上述物理接触问题分别记录。
