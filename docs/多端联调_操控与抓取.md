### 实际链路与边界

隔离 BrainApplication → BrainService 固定三步计划 → 原 TaskRuntime／Runner／Verifier → 导航项目原 8001／9882／ROS g1pilot → 原 SONIC 导航 token 与 decoder → 原生 FQ G1＋O6 MuJoCo。

操控使用远端已有接触规划器、SONIC 原始 ONNX decoder 和原生 O6 手部 PD；在独立副本中增加关门、解钩与撤手阶段。它不是 GR00T 推理或已训练的开关门策略。计划为用户指定的固定导航、开门、关门步骤，本轮没有让 LLM 在线生成动作。

- FQ 资产锁定 `711400c5fbd1f7946ef8bd72477ae457916fce87`；原生模型 `nq=61`、`nv=60`、41 个执行器。与此前 65 个 qpos 的 ROS 导航模型区分。
- 复用隔离导航副本原有五点准入和路径补点修正；本轮只使用冰箱首点。导航控制源码和到达门限没有为成功降级。
- 使用该资产中的可动冰箱；地图与合成扫描中的冰箱位置同步到该版本。定位为仿真真值，不代表实际传感器验收。
- 身体自由浮动，不使用身体固定、手门焊接或门铰链驱动器。该资产右门摩擦损失、阻尼为零，仍未做实物阻力标定。
- 接近、接触与关门保留既有机器人非地面穿透 0.1 mm、冰箱内部穿透 0.001 mm 和单手接触力合量 60 N 的停止门限。

<a id="e-p6-s2"></a>

### 连续状态与任务权威

大脑是唯一任务状态权威，实验执行桥只保存带原 task_id／command_id 的下游命令与结果，不调度下一步。导航完成后仍核对原命令成功、到位、停止及无活动命令。

导航模拟器停止推进物理世界，保存 MuJoCo `mjSTATE_INTEGRATION` 完整积分状态及 SONIC 历史。操控进程读取同一模型与状态；边界逐项比较 qpos／qvel，不重设机器人站位、关节、门角或速度。任一时刻只有一个进程推进该物理回合。开门到位后暂停仿真时钟，待大脑核验并派发原任务的关门命令后继续。仿真时钟暂停不等于实体机器人停止保证。

开门成功要求测得门角至少 25°、门速不高于 1°/s、稳定保持并有手门接触。关门成功要求最终门角绝对值不高于 2°、门速不高于 1°/s、双手离开冰箱、撤手结束；最终底座速度还须低于 0.08 m/s。进程正常退出、中途曾经闭门或手指闭合都不足以通过。

本轮入口、适配器和控制器保存在实验目录；没有将该实验接口部署为正式接待能力。原 ROS 导航桥接的仅导航声明及正式 VLA pick/place 合同保持其原含义，参见[ROS 仿真实验接口](../simulation/backends/ros_navigation/README.md)及[操控接口](接口说明_操控VLA.md)。
