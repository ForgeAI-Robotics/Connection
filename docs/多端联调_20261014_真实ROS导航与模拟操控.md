# 真实 ROS 导航与本地模拟操控联调

日期：2026-10-14。用户要求运行 SIMPLE O6 仿真，明确使用真实导航项目，操控不必真实。
首轮结束后，用户要求继续运行到完整流程通过。后续回合保留失败记录，使用正常大脑
继续接口重试；主大脑、真机服务和原导航源项目未修改或重启。

## 链路与真实性边界

标准 BrainApplication／Runtime → 场景坐标桥接 → 原导航项目 8001 → 9882 →
ROS g1pilot／Dijkstra／nav2point → SONIC → O6 MuJoCo。操控由大脑本地模拟客户端承接，
不调用 VLA、GR00T 或真实抓放。任务触发词为“开始接待（导航仿真＋操控模拟）”，
后端身份为 `reception_ros_sim_manipulation`。操作与核验规则见
[大脑接待流程](接口说明_大脑%20Brain.md#81-流程与请求身份)。

复用 [10 月 12 日第三轮](多端联调_20261012_真实ROS冰箱导航单轮.md#第三轮五点一次完成)
的隔离副本，保留五段准入和 0.05 米路径补点修改；没有新调导航速度、到达门限或超时。
关键导航服务、规划器、跟踪器、物理模型与来源文件逐一核对 SHA256 相同，
进程证据确认实际运行原导航项目各进程，不使用固定路点执行器代替导航。

容器网络为 `none`，ROS 域 119、仅回环通信，经 SSH UNIX socket 连接本机独立大脑。
沿用仿真服务器已存在的五点合同与场景映射，未上传当前真机点位快照。
故本轮验证的是场景语义点上的流程接入，不验证昨天调整后的真机坐标。
定位为 MuJoCo 真值，扫描为合成，不代表真实定位、激光或硬件控制权交接验收。

## 第一回合：首点末端保持失败

任务 `brain-ros-o6-mixed-20261014-01`，准备节点完成后进入 table2 导航。
原命令 `nav-table2-ed2026101401` 于北京时间 10:43:57.578 开始，10:45:08.261 失败。
错误码 `NAVIGATION_EXECUTION_FAILED`，英文原文：

```text
terminal pose adjustment made no progress for 35.0s; navigation_state=HOLD_ARRIVAL_DWELL, current distance=0.15520664303104492m, best distance=0.04825498706922464m
```

导航曾接近目标约 4.83 cm，报错时位置偏差约 15.52 cm，在末端到达保持状态下持续无进展。
这是原导航明确返回的执行失败，不能因曾靠近目标而改判成功；具体末端漂移与控制根因尚未确认。
回执 `success=false`、`reached=false`、`navigation_stopped=true`。
大脑保留失败并进入 `recovery_required`，1 次失败、零重试、零跳过；
模拟抓取及后续导航、模拟放置未执行，不能称为完整混合流程通过。

物理记录共 40275 步、80.55 秒仿真时间，500 Hz 间隔与全部数值有限性检查通过；
非地面接触事件为空，最大躯干倾角约 0.1385 rad。零接触不代表末端到达成功。
确认原导航无在途目标后，锁定本实验导航并保存回执、轨迹，容器正常退出码 0，
独立大脑和 SSH 转发已退出。主大脑任务 ID、state、active 前后一致，未触碰其在途任务。

## 第二回合：横移定位输入中断，重试受地图准入阻塞

任务 `brain-ros-o6-mixed-20261014-02`。table2、relay1、relay2 三段导航均由原导航
返回到达且停止，大脑核验通过；模拟抓取及抓取核验通过，完成 7/11 个节点。
横移命令 `nav-relay3-ed2026101402` 返回 `NAVIGATION_INPUT_INTERRUPTED`：

```text
localization input unavailable; operator approval retained: accepted pose is stale: 0.529147457331419
```

原命令明确失败且 `navigation_stopped=true`。重新核对仿真真值位姿、定位初始化和无在途目标后，
重新批准本实验定位，通过大脑 `/api/task_continue` 创建同一横移段的新命令
`nav-relay3-ed2026101402-r1`。前三段和模拟抓取没有重做。

新命令显示 `waiting_localization_freshness`，但其 `wait_reason` 实际为：

```text
9882 rejected /set-agent-world-goal: HTTP 400: {"error": "localization pose is not in inflated known-free space"}
```

此时复查位姿新鲜度约 0.012 秒，不能继续归因为位姿过期。位姿位于膨胀地图的可通行区之外，
原导航拒绝从当前位置重新规划；8001 依据错误文字含 `localization` 将其显示为新鲜度等待，
状态描述与实际阻塞不符。没有修改地图、门限或直接移动机器人来绕过准入。

通过大脑取消该回合，确认无在途目标后锁定实验导航并退出容器。收尾时重试命令仍记作
`waiting_localization_freshness`，没有到达回执；大脑任务取消不冒充下游命令成功或终态。
本回合 1 次执行失败、1 次显式重试、零跳过，不算完整流程通过。
证据目录：`data/experiments/office_ros_navigation/20261014-mixed-02/`，包含
`original-nav-relay3-ed2026101402.json`、`blocked-retry.json`、重试和取消响应、账本及物理记录。
