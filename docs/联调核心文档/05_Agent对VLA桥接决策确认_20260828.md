## 已确认决策

1. VLA HTTP正式地址确定为：

   ```text
   http://192.168.0.194:8091
   ```

2. 动作通路采用双重确认，不新增推测状态：

   ```text
   VLA终态：policy_stopped=true且navigation_port_ready=true
   DREAM状态：navigation_transport_ready=true
   两者同时成立后，Agent才提交下一段导航。
   ```

   VLA的`navigation_port_ready`必须由真实动作hook/端口交接结果产生，不能根据任务线程退出推断。

3. 本轮固定使用左臂抓取，抓取图片判真固定使用左腕相机，图像键确认为`left_wrist`。Brain–VLA HTTP桥只读订阅NX唯一相机服务，不直接打开USB RealSense。

   Agent侧图片判真只要求确认：

   ```json
   {
     "target_visible": true,
     "target_in_gripper": true,
     "confidence": 0.0,
     "reason": "可乐确实位于灵巧手中"
   }
   ```

   `confidence`由VLM返回，实际通过门限由Agent配置；不再要求单张判真图片证明“已抬离桌面”。VLA动作层仍可使用抬升、负载或视觉跟随作为自身真实抓取证据。

4. place保留现有现场Enter安全批准，不允许HTTP桥模拟或注入Enter：

   ```text
   Agent提交place
   → VLA进入waiting_operator_approval
   → 现场人员检查并按Enter
   → VLA继续执行张手、放置和回stand
   → VLA停止策略并归还动作通路
   → Agent获取动作后图片判真
   ```

   Agent把`waiting_operator_approval`视为运行中状态，不当作失败。place等待上限暂定30分钟。
