# 非主链扩展

本目录集中保存当前主架构之外、仍需评估或兼容的扩展。核心接待链不依赖这些目录；当前主链仍是 Deploy → Master → DREAM / VLA。

- `pbd_ag/`：PBD 语义地图客户端交接材料。仓库目前不包含 `pbd_ag_client` 包本体，相关 PBD backend 不能独立运行。
- `nx_voice/`：Jetson NX 上的麦克风脚本。识别到「开始接待」后，仍向网页 `:8888` 发送这四个字。大脑侧的语音文本入口是 `src/entries/voice/`（`:8890`），本脚本尚未改去调用它，也未纳入控制面板。
- `serve_real/`：旧式真实底盘与机械臂直连桥，默认关闭。部分 Feetech 底盘驱动仍被 Nav2 编码器复用，不能直接删除。

新增主链能力不应放入本目录。扩展重新启用前，需要补齐依赖、配置、测试和运维文档。
